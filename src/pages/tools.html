SyMptOMS Platform

SyMptOMS consists of a smartphone app for patients, a web app for therapists, and server-side services for data storage and analysis.

Our goal

Our goal is to facilitate the creation of apps that use the advanced features of smartphones, so that applications can be tailored to each type of disorder without any technical knowledge.
